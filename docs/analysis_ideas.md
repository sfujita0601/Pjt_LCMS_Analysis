# 解析機能の追加案

少数例 (n = 3〜7 程度) のラット・マウスでの飼料アミノ酸実験を想定して、実験者にとって便利と考えられる解析の候補をまとめたものです。
状態は 2026-10-19 時点のものです。

## 1. moderated t 検定 (経験ベイズ)

- **目的**: n = 3 対 3 のような少数例で、化合物ごとの分散の推定が不安定なことによる偽陽性・偽陰性を減らす
- **方法**: 全化合物の分散の分布から事前分布 (d0, s0²) を推定し、各化合物の分散をそこへ縮小する (Smyth 2004, limma の eBayes と同じ考え方)
- **実装**: `lcms_stats.moderated_t` / `fit_f_dist`。模擬データで、事前分布が推定できること、第一種の過誤が 5% 前後であること、
  Welch の t 検定より検出力が高いことを `tests/test_new_analyses.py` で確認
- **未対応**: 対応のあるデザイン、共変量を含む線形モデル

## 2. 飼料のアミノ酸組成との統合

- **目的**: 飼料中で変えたアミノ酸が血中でも同じ比で変化したか、変化しなかった (恒常性で保たれた) か、
  飼料では変えていないのに変化したアミノ酸はどれか、を一目で見る
- **方法**: 横軸 = 飼料中の含量の log2 比、縦軸 = 血中の log2 幾何平均比 (95% 信頼区間)、y = x の参照線。アミノ酸ごとに分類し、
  アミノ酸をまたいだ相関 (探索用) も出す
- **実装**: `lcms_diet.py`、`ui_diet.py`、デモデータ `scripts/make_demo_diet.py`
- **今後**: 摂食量 (g/日) を入力して「摂取量」の比で比べる、必須 / 非必須アミノ酸での色分け

## 3. フォレストプロット

- **目的**: p 値だけでなく、効果の大きさと推定の確かさを並べて見る。複数の群 vs 対照群 を重ねて比較する
- **実装**: `lcms_plots.forest_plot`、`ui_stats.forest_section`。並べ方 (効果の大きさ・補正後 p・値・名前)、表示数、有意な化合物だけの表示を選べる

## 4. 外れ値サンプルの検出

PCA のスコア (Hotelling の T²・Q 残差) や、ロバストな Z スコアで、全体から外れたサンプルを示す。少数例では 1 匹の外れ値の影響が大きいため、
除外の判断材料 (溶血・採血の失敗などの記録と合わせて確認) として表示する。除外は自動ではなく「使用」のチェックで行う。

## 5. 検出力・必要サンプル数の計算

今回のデータの群内のばらつき (化合物ごとの SD、または moderated t の事後分散) から、次の実験で
「何倍の変化を何匹で検出できるか」を化合物ごとに計算する。

## 6. 共変量の調整 (ANCOVA)

体重・摂食量・絶食時間などを共変量として入力し、調整した群間差を出す。

## 7. 混合効果モデル

同じ個体を複数時点で測った場合 (個体ID・時点の列を使う) に、個体をランダム効果としたモデルで時点 × 群 の効果を検定する。

## 8. 測定順の設計

サンプルの測定順をランダム化 (群が偏らないブロックランダム化) し、プール QC・ブランクを一定間隔で入れたシーケンス表を出力する。
現在は希釈試料を先に測っているため、群と測定順が交絡していないかの確認にも使える。

## 9. 方法の記載文・解析レポートの自動生成

使った設定 (IS 補正・換算係数・検定・多重性補正・閾値) から論文の Methods の文章 (日本語 / 英語) と、
主要な図表をまとめたレポート (HTML / PDF) を作る。

## 10. 基準範囲との比較

過去の実験の対照群の値を蓄積し、今回の対照群がその範囲に入っているか (実験の再現性の確認)、各サンプルが基準範囲から外れているかを示す。

## 11. 代謝経路のエンリッチメント解析

有意に変化した化合物が特定の KEGG 経路に偏っているかを検定する (過剰表現解析)。測定対象がアミノ酸中心で化合物数が少ないため、
結果の解釈には注意が必要。

## 12. 複数の実験の統合

同じ化合物を測った複数の実験 (バッチ・年度) の効果量を、変量効果モデルで統合する。フォレストプロットに実験ごとの効果と統合した効果を並べる。
